# Codebook

The public package contains analytical files generated by the project workflow.

## Included data
- `painel_A_metricas_anuais.csv`: annual Panel A analytical metrics.
- `painel_A_metricas_macrobloco.csv`: annual Panel A metrics by macro-block.
- `serie_mensal_ucrania.csv`: monthly Ukraine analytical series.
- `correspondencia_temporal_codigos_hs.csv`: temporal HS-code correspondence.
- `dicionario_codigos_macroblocos.csv`: mapping of codes to analytical macro-blocks.

## Included results
- `scm_inferencia_randomizacao.csv`: synthetic-control randomization-inference output.
- `serie_interrompida_newey_west.csv`: interrupted time-series estimates using Newey-West inference.

Variable-level definitions should be read together with the manuscript methodology and the transformation logic in the R script.
